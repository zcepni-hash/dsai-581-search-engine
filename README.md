# DSAI 581 — Data & Text Search Engine in Python

A web crawler and search engine built from first principles in Python for DSAI 581 (Boğaziçi University), 
supervised by Assistant Professor Hüseyin Oktay Altun.

## Overview
This project incrementally builds a working search engine over several versions:
- **v3.0** — keyword indexing with duplicate-URL prevention
- **v3.1** — punctuation stripping for cleaner keyword matching
- **v3.2** — case-insensitive normalization
- **PageRank** — a from-scratch implementation of the PageRank algorithm (iterative computation with a damping factor) to rank search results by page importance

Each feature is validated with custom-written test suites to confirm correctness at every stage.
